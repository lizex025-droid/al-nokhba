# النخبة — علوم التأهيل

Arabic RTL academic website for students of the Faculty of Rehabilitation Sciences at the University of Jordan.

## Run locally

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Checks

```bash
npm run typecheck
npm run build
```

The site includes all 13 requested routes. The GPA calculator, navigation, FAQ, and directory search work in the browser. Forms show a local confirmation and do not send data. Study files, tests, study plan PDFs, and professor emails were not supplied, so those sections show clear pending states instead of fabricated records.

The visual direction draws on the spacious progression and restrained motion of [Prenuvo](https://prenuvo.com/) while using custom Al Nokhba visuals and navy, silver, and gold colors. [REA](https://github.com/morluto/rea) was reviewed as the requested reference analysis toolkit; it is not a web app starter or runtime dependency.
